Bem-vindo ao repositório do meu **Plano de Desenvolvimento Individual (PDI)** e Portfólio. 

Desenvolvi este espaço para documentar minha jornada, mapear minha evolução técnica como **Desenvolvedora Back-end** e compartilhar meus principais projetos práticos. 

## 📌 O que você vai encontrar aqui?

- **🎯 Metas e Objetivos:** Acompanhamento dos meus estudos atuais, com forte foco no ecossistema **Java, Spring Boot e Cloud (AWS/Azure)**.
- **📍 Roadmap Técnico:** Uma visão clara das tecnologias que domino (Node.js, Python, bancos relacionais), as que estou estudando e os meus próximos passos (CI/CD, Mensageria).
- **💻 Contribuições & Projetos:** Destaque para projetos práticos reais, como o **Cheffy** (Restaurant ERP), a plataforma **Cultiva** e o **Gestor de Obras**.
- **🧠 Soft Skills:** Mapeamento das minhas habilidades comportamentais em prática e em desenvolvimento.

## 🛠️ Tecnologias Utilizadas no Projeto

Embora meu foco seja o Back-end, decidi construir esta interface para exercitar conceitos modernos de front-end. O projeto foi criado com:

- **[React](https://reactjs.org/)** + **[TypeScript](https://www.typescriptlang.org/)**
- **[Vite](https://vitejs.dev/)** para build ultrarrápido
- **[Tailwind CSS](https://tailwindcss.com/)** para estilização
- **[TanStack Router](https://tanstack.com/router/latest)** para roteamento moderno e tipado
- **[Lucide React](https://lucide.dev/)** para iconografia
- **[Framer Motion](https://www.framer.com/motion/)** (Motion) para animações fluidas

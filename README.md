# My Impact Hub

"Atue como um desenvolvedor web sênior e tech lead. Eu quero desenvolver o meu site pessoal, que funcionará como um 'pitch' otimizado e moderno para eu usar em entrevistas e apresentações. O objetivo é fugir do formato tradicional de currículo e focar em demonstrar valor, capacidade de resolução de problemas e aprendizado contínuo.

1. Stack Tecnológica (Obrigatória):

Framework: Next.js (usando o App Router para melhor performance e organização).

Estilização: Tailwind CSS (para um design limpo, responsivo e moderno).

Adicionais (Opcional): Framer Motion (para micro-interações e animações fluidas) e Lucide React (para ícones).

2. Estrutura e Seções do Site:

Hero Section (Pitch de Elevador): Uma manchete forte focada no valor que entrego (não apenas meu cargo). Deve conter botões de CTA claros, como 'Ver Projetos' e 'Baixar Currículo'.

Projetos como Estudos de Caso: Uma seção de portfólio onde os projetos não são apenas links, mas estruturados no método STAR (Situação, Tarefa, Ação, Resultado). Quero destacar os maiores desafios técnicos que resolvi.

Radar de Estudos e Metas (Timeline/Kanban): Uma seção visual (como uma linha do tempo ou quadro) mostrando o que estou estudando agora, certificações que estou buscando e minhas ideias futuras. Quero mostrar que sou uma profissional em evolução.

Interatividade (Show, Don't Tell): O site deve ter um Dark/Light mode impecável. Além disso, quero incluir um elemento visual interativo que demonstre minhas habilidades na prática (por exemplo, um componente que simula um terminal ou um status em tempo real).

Personalidade e Easter Eggs: Quero adicionar pequenos detalhes para quebrar o gelo em entrevistas (como um 'konami code' que altera o tema, um rodapé criativo ou uma rota de API escondida que retorna meus dados em JSON).

3. Como você deve me ajudar a partir de agora: Gostaria que você me ajudasse passo a passo. Por favor, comece me sugerindo a estrutura de pastas e arquivos ideal no Next.js (App Router) para esse projeto e o código inicial do layout principal (incluindo a configuração básica do Dark Mode com Tailwind). Não gere o site inteiro de uma vez, vamos construir seção por seção."
